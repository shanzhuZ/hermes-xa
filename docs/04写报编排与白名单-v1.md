# 04 写报编排与白名单（v1）

## 目标

- 按 11 步顺序收口，减少 session 热路径上的重 `reconcile_stuck_pipeline`（易触发 Hook 120s 超时、步骤树半截状态）。
- **step7 子步全终态后父节点尽快 completed**；进入步骤 8/9/10 时 **pending/running 的 step7 子步批量 skip**（方案 3 延续）。
- stream 与库：Hook 细状态为主；**`account_report` 已禁用 Java `CoarseStepSync` 写库**。

## 模块

| 文件 | 职责 |
|------|------|
| `scripts/report_04/engine.py` | **v2 编排引擎**：`run_post_tool_light` / `run_pre_llm_auto` / `run_session_finalize_light`；终稿后轻量标 `completed`；7.5 图片管线提示 |
| `scripts/report_04/orchestrator.py` | `infer_gate_step`、`block_tool_reason` 白名单、`advance_to_analysis_phase`（含图片兜底）、`session_end_light` |

| `scripts/report_04/task_store.py` | `finalize_task` 默认轻量 + 图片兜底；`step11+summary` 时 `ready_done`；全量 reconcile 仅 env |

## 触发进入分析（步骤 8～10）

**C：工具或正文任一先到**

1. **正文**：`report_parser.looks_like_entering_analysis_text` 或 `mentions_analysis_steps` → `advance_to_analysis_phase`。
2. **工具**：`should_advance_on_tool`（步骤 7 未收口时又调 web/主页类）→ `pre_tool` 内先收口再门禁。

## 步骤 7.5 图片资产（已接入）

- **主路径**：Skill `7_5_image_assets` — Agent 执行 `python -m image_pipeline.run --task-id <taskId> --force-analyze`。
- **Hook 兜底**：`advance_to_analysis_phase` / `finalize_task` / `session_finalize`（`skip_if_stored`，失败不 fail 任务）。
- **禁止**：在 `post_tool` 热路径跑全量下载。
- 细节见 [`图片资产入库与分析方案.md`](./图片资产入库与分析方案.md) §8.4。

## 环境变量

- `HERMES_REPORT_FULL_RECONCILE=1`：session_end / finalize 额外跑 `reconcile_stuck_pipeline`（修复用，非正常写报）。

## 手工修复

仍可用既有 `step_reconcile.reconcile_collect_child_steps` / `close_collect_parent_if_ready`；或对该 task 临时开 `HERMES_REPORT_FULL_RECONCILE=1` 后结束 session。

## 验收要点

- 新写报：step7 子步终态或正文写「步骤 8」后，**step7 父节点短时间 completed**。
- session_end 默认 **不** 跑全 pipeline；任务 **不会在 step11 未完成时** 因采集完成 alone 标 `completed`（若 8～11 已点亮）。
