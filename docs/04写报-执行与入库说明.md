# 04 写报 · 执行与入库说明（现网）

> 只讲**现网怎么跑、怎么入库、树上每个节点何时算完**。  
> 代码目录：`scripts/report_04/`；统一 Hook 入口：`scripts/db_sink.py`。  
> 任务类型在库里记为「写报任务」（`account_report`）。  
> 产品草案里的「八大阶段 / 资产沉淀」见另文，**未全部改代码**；本文以现网步骤树为准。

---

## 1. 整体怎么跑起来

```
用户发起写报
  → Java 预建任务 + 整棵步骤树（先都是 pending）
  → 「制定执行计划」收口后，启动 Hermes Agent
  → Agent 调工具 / 写正文
  → Hook（db_sink → report_04/sink）拦截：
       工具调用前：门禁、白名单（防抢跑）
       工具调用后：归一化入库 + 校正步骤状态
       模型回复后：解析种子/候选/核验结论/终稿
  → 系统侧自动推关联碰撞、社工库、发文准备等
  → 「画像报告」终稿入库 → 任务 completed
```

**一句话**：Agent 负责「去采、去写」；Hook 与系统脚本负责「入库、改树、开门禁」。树上多数采集节点**不是**工具一返回就绿，而是**业务表有数据（或明确无数据可跳过）**才收口。

## 3. 树上有哪些节点（按展示顺序）

树挂在「制定执行计划」下，再拆成七个大阶段壳；壳下面挂真正干活的业务步。平台子节点在运行中按候选/可信账号动态挂上。

```
制定执行计划
├─ 1. 锁定目标
│   └─ {平台} MCP/Apify Agent 采集          ← 只采种子主页
├─ 2. 线索发现
│   ├─ Maigret Agent 跨平台收集
│   └─ 网页检索 Agent 候选发现
├─ 3. 账号采集
│   └─ MCP/Apify Agent 候选主页采集        ← 父汇总
│       └─ {平台} Agent 主页采集 · @xxx    ← 按平台动态
├─ 4. 关联碰撞
│   ├─ 信息核验流 Agent 核查               ← 父汇总
│   │   ├─ 文本流核验 Agent
│   │   └─ 图片流核验 Agent
│   ├─ 相似账号认定 Agent
│   └─ 社工库核验 Agent
├─ 5. 内容采集
│   └─ 跨平台发文采集 Agent                ← 父汇总
│       ├─ {平台} Agent 发文采集           ← 按平台动态
│       └─ {平台}视频分析                  ← 旁路，挂在发文下
├─ 6. 深度研判
│   ├─ 图片流 Agent 分析
│   ├─ 观点与涉华分析 Agent
│   └─ PII 与圈层分析 Agent
└─ 7. 报告生成
    └─ 画像报告 Agent
```

说明：

- **大阶段壳**（1～7）：主要给人看进度；子业务步都终态后由系统收口。
- **父汇总**（候选主页采集 / 信息核验 / 跨平台发文）：本身不采数据，等子节点终态。
- **视频分析**：旁路。一般**不挡住**「发文父节点收口」和「进入深度研判」；终稿前可能再卡一下视频是否跑完。
- **图片资产管线**（下载/OCR 等）：发文后后台跑，**不单独占树上一个节点**。

## 4. 完成条件：工具结束，还是入库才算完？

### 4.1 总原则

| 类型 | 典型节点 | 何时算完成 |
|------|----------|------------|
| **入库驱动** | 种子采集、各平台主页、各平台发文、相似账号认定 | 对应业务表有行，或明确「采不到」标跳过 |
| **工具结束≈完成** | Maigret 跨平台收集 | 指定工具成功返回即可（候选会尽量入库） |
| **配额/安静期/汇总** | 网页检索候选发现 | 检索次数/安静期到了，或 Agent 写出步骤 3 汇总即可收口，**不强制**候选条数 |
| **系统自动** | 文本/图片核验、社工库、父节点/大阶段壳 | Hook 或后台进程写完，不靠 Agent 点完成 |
| **正文驱动** | 深度研判三步、画像报告 | Agent 写出合格分析块/四章节终稿 |

**常见误解**：以为「Agent 调完工具节点就绿」。  
现网对主页/发文更严——**库里有主页行/发文行（或已尝试且确认 0 条可跳过）**才绿；没试过的平台**禁止空跳过**硬闯下一阶段。

### 4.2 逐节点说明

#### 制定执行计划

- **做什么**：Java 侧出规划文案，收口后才真正拉起 Agent。
- **何时完成**：规划写完 → 系统标完成。不是 Agent 工具驱动。

#### 1. 锁定目标（壳）

- **子节点 · 种子主页采集**（标题随平台变，如「Twitter MCP Agent 采集」）  
  - **做什么**：只采种子账号主页，不采发文。  
  - **何时完成**：**主页入库**后系统标完成；空结果可失败并中止。  
  - **主要落表**：账号主页表、身份流初建、工具原始输出表。

#### 2. 线索发现（壳）

- **Maigret Agent 跨平台收集**  
  - **做什么**：同名探测，产出候选草稿。  
  - **何时完成**：Maigret 工具**成功返回**即完成（偏工具结束）。  
  - **落表**：跨平台候选表（有则写）。

- **网页检索 Agent 候选发现**  
  - **做什么**：搜索/浏览器补候选。  
  - **何时完成**：达到检索预算、安静期/次数上限，或 Agent 输出「步骤 3 汇总」类正文；**不强制**候选必须很多。  
  - **落表**：跨平台候选表。  
  - **门禁**：Maigret 未终态前，不允许开网页检索。

- **线索两条都终态后**：才按候选物化「各平台主页」子节点。

#### 3. 账号采集（壳）

- **MCP/Apify Agent 候选主页采集**（父）  
  - **何时完成**：下面各平台子节点全部终态（完成/跳过/失败都算终态），且线索发现已终态。

- **{平台} Agent 主页采集**（动态子）  
  - **做什么**：按候选去采该平台主页。  
  - **何时完成**：**该平台主页已入库**→完成；无采集通道或无线索→跳过；工具失败可先 running 再跳过。  
  - **落表**：账号主页表、身份流。

#### 4. 关联碰撞（壳）

须先满足：**种子完成 + 候选主页父节点及子节点终态**，系统才拉开本阶段。

- **信息核验流 Agent 核查**（父）  
  - **何时完成**：文本流、图片流两个子节点都终态。

- **文本流核验 Agent**  
  - **做什么**：规则/模型比对文本身份流。  
  - **何时完成**：系统比对写完身份流校验结果，或 Agent 带「文本核验结论」标记；无文本流则跳过。  
  - **落表**：身份流表（校验字段）。

- **图片流核验 Agent**  
  - **做什么**：后台图片比对管线。  
  - **何时完成**：管线跑完（有图/无图分别完成或跳过）。  
  - **落表**：身份流、图片相关表。

- **相似账号认定 Agent**  
  - **做什么**：根据主页 + 核验流收敛「可信账号」清单。  
  - **何时完成**：**可信账号表写完**后系统标完成（强入库驱动，主路径是系统推，不靠 Agent 口头完成）。

- **社工库核验 Agent**  
  - **做什么**：用可信账号去离线社工库碰撞。  
  - **何时完成**：有命中→完成；无命中→跳过；覆盖度/超时可失败放行。  
  - **落表**：社工库命中表。  
  - **门禁**：须「信息核验父节点完成 + 相似账号认定完成」后才开。

#### 5. 内容采集（壳）

须「相似账号认定完成 + 社工库终态」后才允许发文工具。

- **跨平台发文采集 Agent**（父）  
  - **何时完成**：各平台发文子节点终态；也可在「发文实质已齐」时先放行深度研判，再慢慢关父壳。

- **{平台} Agent 发文采集**（动态子）  
  - **做什么**：只对可信账号平台采发文。  
  - **何时完成**：**发文表有数据**→完成；已调工具但 0 条→跳过；**没尝试过的平台不能空跳过进研判**。  
  - **落表**：发文表；随后可触发图片资产、视频旁路。

- **{平台}视频分析**（动态旁路）  
  - **做什么**：有可下载视频则后台分析。  
  - **何时完成**：视频进程终态。  
  - **注意**：一般不挡发文父壳；终稿前可能再检查视频是否结束。

#### 6. 深度研判（壳）

须发文侧实质就绪（或父壳终态）后进入。

- **图片流 Agent 分析** / **观点与涉华分析 Agent** / **PII 与圈层分析 Agent**  
  - **做什么**：纯研判，写分析正文。  
  - **何时完成**：Agent 写出独立分析块 → 写入展示记录并标完成；终稿时也可回填；一直没有则终稿时跳过。  
  - **落表**：展示记录表（给前端详情），不是「采账号」那种主数据表。

#### 7. 报告生成（壳）

- **画像报告 Agent**  
  - **做什么**：输出四章节画像终稿。  
  - **何时完成**：识别为终稿正文，且视频门禁通过 → 写入对话「摘要」并标本步完成；同时尽量收口发文相关未了事项。  
  - **任务级完成**：本步完成 **且** 库里已有摘要类对话 → 任务状态改为已完成。

## 5. 数据进哪些表（按用途）

仓库里**没有**单独的「账号总表」一名；账号相关主要是主页表 + 可信账号表。

| 表（中文理解） | 何时写入 |
|----------------|----------|
| 任务表 `hermes_tasks` | 建任务；阶段/状态随流程改 |
| 对话表 `hermes_user_dialogues` | 用户输入、模型回复、**终稿摘要** |
| 步骤树 `collect_phase_steps` | Java 预建；全程改状态/文案 |
| 工具原始输出 `hermes_tool_outputs` | 每次工具调用后 |
| 账号主页 `collect_profiles` | 种子与候选主页采集 |
| 跨平台候选 `cross_platform_candidates` | Maigret / 网页检索 |
| 身份流 `collect_identity_streams` | 主页拆流 + 文本/图片核验结果 |
| 可信账号 `collect_validated_accounts` | 「相似账号认定」系统收敛 |
| 社工库命中 `collect_osint_hits` | 社工库查询 |
| 发文 `collect_posts` | 发文工具归一化后 |
| 图片 `collect_images`（及本地图片目录） | 核验/发文后图片管线 |
| 展示记录 `collect_display_records` | 研判展示、身份流/可信账号双写展示 |
| 任务汇总 `collect_task_summaries` | 任务收尾汇总 |

工具返回 → `collect_01` 归一化器 → `task_store` 落业务表 → 再校正步骤树上的完成/跳过。

## 6. 推进节奏（门禁顺序）

硬顺序（前一步不终态，后一步工具会被拦或系统不推）：

1. Maigret 终态 → 才允许网页检索  
2. Maigret + 网页检索都终态 → 才生成/更新各平台主页子节点  
3. 种子完成 + 主页采集齐 → 才进信息核验  
4. 信息核验完成 → 才跑相似账号认定  
5. 信息核验 + 相似账号认定完成 → 才开社工库  
6. 相似账号认定完成 + 社工库终态 → 才允许发文采集  
7. 发文实质就绪 → 才进深度研判与画像报告  

系统在模型回合之间还会自动推一档（例如：主页齐了开核验 → 核验完写可信账号 → 再开社工库 → 再准备发文子节点），避免 Agent 卡在「下一步该干什么」。

会话想结束时：若碰撞未齐或发文未落地，会要求继续；也可走「续跑」同会话再推发文/研判/写报。

## 7. 速查：谁靠入库、谁靠工具/正文

| 阶段 | 入库才算完（主） | 工具/正文即可 | 系统自动收口 |
|------|------------------|---------------|--------------|
| 锁定目标 | 种子主页 | — | 大阶段壳 |
| 线索发现 | 候选（尽量写） | Maigret；网页检索配额/汇总 | — |
| 账号采集 | 各平台主页 | — | 父汇总壳 |
| 关联碰撞 | 可信账号；社工命中；身份流校验字段 | Agent 文本核验结论（辅助） | 文本/图片核验主路径、父壳 |
| 内容采集 | 各平台发文 | — | 父汇总；视频旁路 |
| 深度研判 | 展示记录 | 三份分析正文 | 终稿回填/跳过 |
| 报告生成 | 摘要对话 | 四章节终稿正文 | 任务 completed |

---

## 8. 和前端树的关系

- 前端密塔树读步骤表（Java 树查询服务），展示的是上面那棵树。  
- 「完成」以步骤表状态为准；状态由 Hook/`task_store` 根据**库表事实 + 门禁**改写，不是前端自己改。  
- 轮询任务是否结束：通常要求摘要对话已有，且「7. 报告生成」大阶段已完成。
