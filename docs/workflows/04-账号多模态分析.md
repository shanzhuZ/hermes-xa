# 04 · 账号多模态分析

> **交互模式**：密塔 AI 深度模式 —— 对用户确认的**模态类型、分析目标、样本范围**执行文本/图像/视频/音频等联合分析。  
> **定位**：在采集与核查基础上，对账号内容进行**深度解读**，支撑虚拟身份判定、行为画像与报告论据。

---

## 一、业务目标

针对账号关联的**多模态内容**（博文文本、图片、视频帧、头像、截图、OCR 结果等），按用户选定方向输出结构化分析结果。

| 产出 | 说明 |
|------|------|
| 模态分析报告 | 按模态拆分的分析条目 |
| 跨模态关联 | 图文一致性、人设矛盾点 |
| 风险标签 | 涉政、广告、虚假、AI 生成等（可配置） |
| 可视化摘要 | 话题分布、情感倾向、时间线特征（可选） |

---

## 二、触发条件

- 从 **03 账号核查** 发现头像/内容疑点跳转
- 从 **01 采集** 完成后用户主动选择「深度分析内容」
- 用户指令：「分析这个账号发的图片和文案」

**前置输入**：

- 已采集的内容样本（帖文、媒体 URL、本地缓存）
- 或用户上传的补充材料（截图、链接）

---

## 三、深度模式交互流程

```
输入分析对象（账号 / 帖子列表 / 单条内容）
    │
    ▼
【确认点 A】分析范围？
    ├─ 全量已采集内容
    ├─ 按时间/关键词筛选子集
    ├─ 仅核查阶段标记的可疑条目
    └─ 用户手动勾选帖子 ID
              │
              ▼
【确认点 B】启用哪些模态？
    ├─ 文本（博文、评论、简介）
    ├─ 图像（头像、配图、相册）
    ├─ 视频（封面、关键帧、字幕/OCR）
    ├─ 音频（如有，转写后分析）
    └─ 跨模态一致性（图文/人设对照）
              │
              ▼
【确认点 C】分析目标（可多选）？
    ├─ 话题与立场归纳
    ├─ 情感 / 情绪倾向
    ├─ 虚假信息与谣言特征
    ├─ 图像真实性（网图、AI 生成、篡改）
    ├─ 人脸/人物一致性（多图比对）
    ├─ OCR 文字提取与敏感信息
    ├─ 行为模式（发帖习惯、互动风格）
    └─ 自定义分析问题列表
              │
              ▼
【确认点 D】分析深度与成本？
    ├─ 快速抽检（Top N 条）
    ├─ 标准（全部样本，单模态）
    └─ 深度（全模态 + 视频抽帧加密）
              │
              ▼
    ┌─ 执行多模态流水线 ─┐
    └────────────────────┘
              │
              ▼
【确认点 E】展示分析摘要，是否钻取？
    ├─ 对某条帖子/某张图展开详情
    ├─ 将结论回写 03 核查证据
    ├─ 进入 05 生成报告
    └─ 结束
```

---

## 四、模态与分析能力矩阵

| 模态 | 典型输入 | 分析能力 | 工具 |
|------|----------|----------|------|
| 文本 | 博文、评论、简介 | 主题、情感、实体、立场 | 模型 + NLP 脚本 |
| 图像 | 头像、配图 | 网图检索、AI 生成检测、OCR | Vision MCP、OCR MCP |
| 视频 | 用户视频 | 关键帧、字幕、封面分析 | 视频分析工具 + OCR |
| 跨模态 | 图文帖子 | 文案与图片是否匹配、人设矛盾 | 联合 Prompt + 规则 |

---

## 五、各确认点说明

### 确认点 B · 模态选择

> 已采集内容含：博文 30 条（含图 12 条）、视频 3 条、头像 1 张。  
> 请选择分析模态：  
> - [x] 文本  
> - [x] 图像  
> - [ ] 视频（3 条，预计耗时较长）  
> - [x] 跨模态一致性  

### 确认点 C · 分析目标

**舆情 / 核查场景推荐组合**：

| 场景 | 推荐目标 |
|------|----------|
| 虚拟身份核查 | 图像真实性 + 人脸一致性 + 文本人设矛盾 |
| 舆情研判 | 话题归纳 + 情感倾向 + 谣言特征 |
| 事件时间线 | 行为模式 + 文本实体抽取 + 时间戳对齐 |

### 确认点 D · 深度档位

| 档位 | 说明 | 适用 |
|------|------|------|
| 快速 | 抽检 10 条或全部图片缩略分析 | 初筛 |
| 标准 | 全部文本 + 全部图片 | 常规 |
| 深度 | 含视频抽帧、逐帧 OCR、多图比对 | 重点账号 |

## 七、与上下游关系

```
01 采集 ──内容样本──▶ 04 多模态分析 ◀──疑点条目── 03 核查
                            │
                            ▼
                      05 账号核查报告
```

---

## 八、原则（强制）

1. **媒体分析必须标注来源**（帖子 ID、URL、采集时间）  
2. **图像类结论需附依据**（相似图链接、OCR 原文、模型判定说明）  
3. **视频深度分析前提示耗时**，需用户确认点 D 明确同意  
4. **敏感内容**按配置脱敏后再进入长期存储
