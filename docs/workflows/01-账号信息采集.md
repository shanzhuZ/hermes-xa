# 01 · 账号信息采集

> **交互模式**：密塔 AI 深度模式 —— 用户下发任务后，系统分步提问、用户确认后再执行，不一次性跑完全流程。  
> **定位**：单平台、单账号的**原始数据拉取**入口，为后续跨平台收集、核查、多模态分析提供素材。

---

## 一、业务目标

在**指定社交平台**上，按用户确认的条件（关键词、时间、数量等），采集目标账号的**可公开信息**（资料、发帖、互动等），并结构化入库。

| 产出 | 说明 |
|------|------|
| 账号基础资料 | 昵称、简介、粉丝/关注、注册线索、认证状态等 |
| 内容样本 | 帖子/视频/评论等，带时间戳与互动量 |
| 采集元数据 | 平台、采集时间、筛选条件、数据来源工具 |

---

## 二、触发条件

- 用户输入：平台 + 账号标识（用户名 / UID / 主页链接 / 手机号线索等）
- 或从上游任务带入：已解析的 `platform` + `account_id`

**示例用户指令**：

> 采集微博账号 @某某 的信息

---

## 三、深度模式交互流程

```
用户下发账号
    │
    ▼
【确认点 A】是否按关键词筛选采集内容？
    ├─ 否 → 采集全部可见内容（仍受时间/数量限制）
    └─ 是 → 【确认点 B】输入关键词（支持多词、AND/OR）
              │
              ▼
【确认点 C】采集时间范围？
    ├─ 最近 N 天
    ├─ 指定起止日期
    └─ 不限（受平台与数量上限约束）
              │
              ▼
【确认点 D】采集数量上限？
    ├─ 帖子/视频条数
    ├─ 评论条数（可选）
    └─ 是否包含转发/回复
              │
              ▼
    ┌─ 执行采集（调用对应平台 MCP）─┐
    └──────────────────────────────┘
              │
              ▼
【确认点 E】展示采集摘要，询问是否继续？
    ├─ 调整条件重新采集
    ├─ 进入「02 跨平台账号收集」
    ├─ 进入「03 账号核查」（批量判定是否本人真实）
    └─ 结束本阶段
```

---

## 四、各确认点详细说明

### 确认点 A · 是否按关键词采集

| 选项 | 系统行为 |
|------|----------|
| **是** | 仅采集标题/正文/话题命中关键词的内容 |
| **否** | 按时间+数量拉取该账号可见内容，不做文本过滤 |

**系统提示文案示例**：

> 已识别目标：**微博 @某某**（UID: 123456789）  
> 是否需要**按关键词**筛选采集内容？  
> - [1] 是，我只关心与某事件/话题相关的内容  
> - [2] 否，按时间范围尽量全量采集  

---

### 确认点 B · 关键词（仅 A=是 时）

| 字段 | 说明 |
|------|------|
| 关键词列表 | 支持多个，如 `烟花厂`、`浏阳`、`爆炸` |
| 匹配范围 | 正文 / 话题 / 评论（可勾选） |
| 逻辑 | 默认 OR；可选 AND |

---

### 确认点 C · 时间范围

| 选项 | 典型值 |
|------|--------|
| 快捷 | 7 天 / 30 天 / 90 天 / 1 年 |
| 自定义 | `2026-05-01` ~ `2026-05-31` |
| 不限 | 受平台 API 与单次上限约束，需二次确认 |

---

### 确认点 D · 数量与范围

| 字段 | 默认值建议 | 上限说明 |
|------|------------|----------|
| 主内容条数 | 50 | 可配置，防止单次过大 |
| 每条评论数 | 20 | 可选开启 |
| 含转发/回复 | 否 | 舆情场景常需要，可勾选 |

---

### 确认点 E · 采集完成后的下一步

**系统展示摘要**（示例）：

| 项 | 结果 |
|----|------|
| 平台 | 微博 |
| 账号 | @某某 |
| 资料 | 已获取 |
| 命中帖子 | 23 条 |
| 评论 | 156 条 |
| 耗时 | 42s |

**系统追问**：

> 采集已完成。接下来您希望：  
> - [1] **补充采集**其他平台同一人账号（→ 02 跨平台账号收集）  
> - [2] **进入核查**（将账号加入列表，→ 03 批量判定是否本人）  
> - [3] **调整条件**重新采集本平台  
> - [4] **结束**，仅保留本次采集结果

---

## 八、异常与边界

- **账号不存在 / 已注销**：在确认点 A 之前完成校验，直接返回，不进入采集
- **私密账号**：提示可见范围受限，仅采集公开部分
- **平台限流**：提示剩余配额，建议缩小时间范围或数量
- **用户中途取消**：保留已确认参数，支持从上一确认点恢复

## 九、示例对话

```
用户：采集微博 @浏阳网友 的信息，和烟花厂事故有关的。

系统：已识别微博账号 @浏阳网友。是否只采集与「烟花厂事故」相关的内容？
      [1] 是  [2] 否，全量采集

用户：1

系统：请输入关键词（多个用逗号分隔），或直接确认默认：烟花厂,浏阳,爆炸
用户：烟花厂,浏阳,爆炸

系统：采集时间范围？
      [1] 最近30天  [2] 最近90天  [3] 自定义  [4] 不限

用户：3 → 2026-05-01 至 2026-05-15

系统：最多采集多少条博文？[默认 50]
用户：30

系统：（执行采集）… 完成。共 18 条博文、92 条评论。
      是否采集该用户在其他平台（微信、B站等）的账号？[1]是 [2]否 [3]先核查

用户：1  → 跳转 02-跨平台账号收集
```
