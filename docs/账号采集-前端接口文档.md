# 账号采集 — 前端接口文档

> **前端只调本服务** `http://127.0.0.1:4377`（Spring Boot），**禁止**直连 Hermes Gateway（`8642`）。  
> 建会话、下任务、查进度均由 Java 封装；Gateway / MySQL / Hook 对前端不可见。

---

## 三个 ID 怎么用

| 字段 | 谁生成 | 前端要不要存 |
|------|--------|--------------|
| `sessionId` | Java 调 Gateway 建会话后返回 | 要，同页多轮对话复用 |
| `taskId` | Java 每次下任务时生成 | 要，轮询进度、区分多次采集结果 |
| `pollTreeUrl` | Java 返回的相对路径 | 可直接拼基址轮询 |

---

## 前端只做三件事

| 步骤 | 接口 | 说明 |
|------|------|------|
| ① 用户发话 | `POST /api/collect/start` | 拿到 `sessionId` + `taskId` |
| ② 看进度 | `GET /api/tasks/{taskId}/tree` | 每 2～3 秒轮询，直到 `status` 为 `completed` / `failed` |
| ②b 思考过程 | `GET /api/tasks/{taskId}/thoughts` + SSE `.../thoughts/stream` | 完成态用 GET 的 `finalContent`；进行中只拼 SSE 的 `assistant.delta.content` |
| ③ 点步骤 | `GET /api/tasks/{taskId}/steps/{stepKey}/data` | 展示该步业务表数据（人物/候选/发文等） |
| ④ 看终稿 | `GET /api/tasks/{taskId}/final-answer` | 单独拉模型三节报告全文（业务报告，非思考区） |
| ⑤ 点节点 | `GET /api/tasks/{taskId}/nodes/{nodeId}` | 看工具出参、步骤说明等 |

## 场景 A：第一轮新对话（最常用）

用户第一次输入，本地**还没有** `sessionId`。

```http
POST http://127.0.0.1:4377/api/collect/start
Content-Type: application/json

{
  "message": "account-intelligence-collect 采集推特 @whyyoutouzhele，需要跨平台采集"
}
```

**响应 202**

```json
{
  "sessionId": "api_1783491476_aee0b4cf",
  "taskId": "a5a1a90b-41b7-4f49-9fc3-40f04332c8d5",
  "newConversation": true,
  "status": "pending",
  "pollTreeUrl": "/api/tasks/a5a1a90b-41b7-4f49-9fc3-40f04332c8d5/tree",
  "pollTaskUrl": "/api/tasks/a5a1a90b-41b7-4f49-9fc3-40f04332c8d5",
  "thoughtsUrl": "/api/tasks/a5a1a90b-41b7-4f49-9fc3-40f04332c8d5/thoughts",
  "thoughtsStreamUrl": "/api/tasks/a5a1a90b-41b7-4f49-9fc3-40f04332c8d5/thoughts/stream",
  "stream": {
    "mode": "java_relay",
    "enabled": true,
    "url": "/api/tasks/a5a1a90b-41b7-4f49-9fc3-40f04332c8d5/thoughts/stream",
```

### 第五类自定义（taskType=custom）

自然语言开任务，不限主题。库内 `task_type=account_custom`，Skill=`account-intelligence-custom`。

```http
POST http://127.0.0.1:4377/api/collect/start
Content-Type: application/json

{
  "taskType": "custom",
  "message": "帮我梳理某某人物的公开舆论要点，并给结论"
}
```

启动后预插 `step_plan`（制定执行计划）；后续步骤由模型经 flow 接口或 `python -m custom_05.flow_cli` 动态写入。进度仍轮询 `GET /api/tasks/{taskId}/tree`。

```http
POST /api/tasks/{taskId}/flow/upsert
POST /api/tasks/{taskId}/flow/begin
POST /api/tasks/{taskId}/flow/finish
```

## ② 轮询进度树（必接）

```http
GET http://127.0.0.1:4377/api/tasks/{taskId}/tree
```

**响应 200** 核心字段：

| 字段 | 用途 |
|------|------|
| `status` | 任务整体：`pending` / `running` / `completed` / `failed`，用于停止轮询 |
| `root` | 用户问题根节点 |
| `nodes[]` | 步骤主节点（步骤一～六） |
| `nodes[].children[]` | 工具子节点 |
| `nodes[].statusLabel` | 展示文案：`结论明确` / `进行中` / `待执行` / `信息缺失` |
| `summary` | 终稿摘要，完成后非 null |

**停止轮询**：`status === 'completed'` 或 `status === 'failed'`。

## ③ 步骤业务数据（点击步骤主节点）

```http
GET http://127.0.0.1:4377/api/tasks/{taskId}/steps/{stepKey}/data
```

`stepKey` 与 tree 里步骤节点 `id` 一致，例如 `step1_seed`、`step2_cross_platform`、`step3_profiles`、`step3_streams`、`step4_text_compare`、`step4_image_compare`、`step5_validated`、`step6_posts`、`step6_post_twitter` 等。

**响应 200** 示例：

```json
{
  "taskId": "a5a1a90b-41b7-4f49-9fc3-40f04332c8d5",
  "stepKey": "step3_profiles",
  "title": "步骤三：采集人物资料",
  "status": "completed",
  "statusLabel": "结论明确",
  "message": null,
  "dataType": "collect_profiles",
  "recordCount": 3,
  "records": [
    {
      "id": 1,
      "platform": "twitter",
      "accountHandle": "@whyyoutouzhele",
      "displayName": "...",
      "bio": "...",
      "followerCount": 12345
    }
  ]
}
```

| dataType | 对应表 | 典型 stepKey |
|----------|--------|--------------|
| `collect_profiles` | 人物资料 | `step1_seed`、`step3_profiles` |
| `cross_platform_candidates` | 跨平台候选 | `step2_cross_platform` |
| `collect_identity_streams` | 身份流 | `step3_streams`、`step4_text_compare`、`step4_image_compare` |
| `collect_validated_accounts` | 校验通过账号 | `step5_validated` |
| `collect_posts` | 发文 | `step6_posts`、`step6_post_{platform}` |

**404**：`taskId` 不存在，或该 `stepKey` 在 `collect_phase_steps` 中尚无记录。

## ②b 思考过程（思考面板，非报告区）

详细方案见 [`思考流与步骤树同步落库实施方案.md`](思考流与步骤树同步落库实施方案.md)。

### 查询终稿 / 模式

```http
GET http://127.0.0.1:4377/api/tasks/{taskId}/thoughts
```

**响应 200 示例（已完成）：**

```json
{
  "taskId": "a5a1a90b-41b7-4f49-9fc3-40f04332c8d5",
  "taskStatus": "completed",
  "finalContent": "……assistant.completed 全文……",
  "hasFinal": true,
  "mode": "final",
  "streamAvailable": true,
  "thoughtsStreamUrl": "/api/tasks/.../thoughts/stream"
}
```

| `mode` | 前端行为 |
|--------|----------|
| `final` | 思考面板直接渲染 `finalContent`（任务刷新可回放） |
| `live` | 面板可空；连 SSE，**只追加** `eventType === "assistant.delta"` 的 `content` |

进行中刷新（I1）：先 `GET /thoughts/timeline` 渲染已落库 `_thinking` 整句，再连
`GET /thoughts/stream?afterSeq={lastSeq}`；实时区仍只拼 `assistant.delta`。
详见 [思考流可回放-timeline约定.md](./思考流可回放-timeline约定.md)。

### 实时流

```http
GET http://127.0.0.1:4377/api/tasks/{taskId}/thoughts/stream?afterSeq=0
Accept: text/event-stream
```

实时只拼 `assistant.delta.content`。历史回放用 `GET /thoughts/timeline`（`tool.progress` + `_thinking`）。
可选 `afterSeq` 续传，避免刷新断层。

### 思考时间线（历史 / 刷新）

```http
GET http://127.0.0.1:4377/api/tasks/{taskId}/thoughts/timeline?afterSeq=0
```

返回 `events[]`（仅 `_thinking` 整句）与 `lastSeq`。

## ④ 模型终稿（报告区）

```http
GET http://127.0.0.1:4377/api/tasks/{taskId}/final-answer
```

优先返回 `hermes_user_dialogues` 中 `msg_type = summary` 的三节报告；若无则回退最新 `assistant_reply`。

**响应 200**（已就绪）：

```json
{
  "taskId": "a5a1a90b-41b7-4f49-9fc3-40f04332c8d5",
  "type": "summary",
  "msgType": "summary",
  "content": "## 一、种子账号\n...",
  "createdAt": "2026-07-08T10:00:00",
  "ready": true
}
```

**响应 200**（尚未入库，`ready: false`）：继续轮询 tree 或稍后重试本接口。

## 其他接口（可选）

```http
GET /api/tasks/{taskId}                      # 任务概要
GET /api/conversations/{sessionId}/tasks     # 会话内历史 task 列表
```

### 历史问答（按任务，独立于 /api/dialogues）

```http
GET http://127.0.0.1:4377/api/history/tasks?page=1&pageSize=20
GET http://127.0.0.1:4377/api/history/tasks?taskType=collect&status=completed
GET http://127.0.0.1:4377/api/history/tasks/{taskId}
DELETE http://127.0.0.1:4377/api/history/tasks/{taskId}
```

| 参数 | 说明 |
|------|------|
| `page` / `pageSize` | 分页，默认 1 / 20，pageSize 上限 200 |
| `taskType` | 可选。`collect` / `expand` / `verify` / `report` / `custom` 或库内 `account_*` |
| `status` | 可选精确过滤：`pending` / `running` / `completed` / `cancelled`（默认四者都返回，不含 failed） |

列表每条为**一个任务**，含提问、payload、是否有答案预览（`answerMsgType`：`cancelled`/`summary`/`user_input`）、`detailUrl`。

详情一次返回：`question`、`report`（终稿或取消态）、`profiles`、`posts`、`images`、`counts`。

`report.msgType` 优先级与 `/api/dialogues` 一致：`cancelled` > `summary` > `user_input`。

`images[]` 在 `storageStatus=已存储` 时会从 HBase（或本地回退）读出原图，填充：
- `dataUrl`：`data:image/...;base64,...`，前端可直接 `<img src>`
- `hasStoredBytes`：是否读到存储字节
- `imageUrl`：仍保留 `/api/images/{imageId}/bytes`（超大图或读失败时用）

单图超过约 1.5MB 时不嵌入 `dataUrl`，请改用 `imageUrl`。

删除：按 `taskId` 清 MySQL 中该任务全部关联表（含 `hermes_tasks`）；`404` 任务不存在。返回 `ok`、`taskId`、`deleted`（各表删除行数）。**不删** HBase 图片二进制。

### 图片资产（独立管线，不依赖 01～04 步骤树）

```http
GET http://127.0.0.1:4377/api/tasks/{taskId}/images?page=1&pageSize=20
GET http://127.0.0.1:4377/api/tasks/{taskId}/images?sourceType=post_media&analyzeStatus=completed
GET http://127.0.0.1:4377/api/images/{imageId}
GET http://127.0.0.1:4377/api/images/{imageId}/bytes
```

| 参数 | 说明 |
|------|------|
| `sourceType` | 可选英文枚举：`profile_avatar` / `profile_cover` / `post_media` |
| `analyzeStatus` | 可选：`pending` / `running` / `completed` / `failed` / `skipped` |
| `storageStatus` | 可选：`pending` / `downloading` / `stored` / `failed` |

列表项中 `sourceType` / `storageStatus` / `analyzeStatus` 为中文展示，对应 `*Code` 为库内英文值；`imageUrl` 指向原图接口。

原图接口：`404` 无记录或无字节；`409` 尚未入库；`500` 存储读取异常。

### 历史对话

```http
GET http://127.0.0.1:4377/api/dialogues?page=1&pageSize=20
GET http://127.0.0.1:4377/api/dialogues?page=1&pageSize=20&taskType=collect
```

| 参数 | 说明 |
|------|------|
| `page` / `pageSize` | 分页，默认 1 / 20，pageSize 上限 200 |
| `taskType` | 可选。前端短码 `collect` / `expand` / `verify` / `report`，也支持库内 `account_*` |

**折叠规则**：每个 `taskId` 只返回一条，且仅 `user_input` / `summary` / `cancelled`；
优先级 `cancelled` > `summary` > `user_input`。`payload` 一律取同任务 `user_input.payload_json`。

历史详情 `/api/history/tasks/{taskId}` 的 `report` 同样认 `cancelled`（优先于 summary）。

响应中 **`taskType` 为中文业务名**（如「账号信息采集」），不再返回英文枚举。

```json
{
  "page": 1,
  "pageSize": 20,
  "total": 90,
  "taskType": "账号信息采集",
  "list": [
    {
      "id": 367,
      "taskId": "...",
      "sessionId": "...",
      "role": "assistant",
      "content": "...",
      "msgType": "summary",
      "taskType": "账号信息采集",
      "payload": {},
      "createdAt": "..."
    }
  ]
}
```

未传 `taskType` 时响应无顶层 `taskType` 字段，`list` 内每条仍带中文 `taskType`。

## 错误码

| HTTP | 含义 |
|------|------|
| 400 | 缺少 message 等参数 |
| 409 | 当前会话还有任务在跑，须等结束再提交 |
| 404 | taskId 不存在 |
| 502 | Java 调 Gateway 建会话失败（前端只需提示「服务暂不可用」） |

## 最小前端代码

```javascript
const API = 'http://127.0.0.1:4377';

// ① 用户发话（第一轮不传 sessionId）
let sessionId = localStorage.getItem('sessionId') || '';
const start = await fetch(API + '/api/collect/start', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ sessionId: sessionId || undefined, message: userInput }),
}).then(r => r.json());

sessionId = start.sessionId;
localStorage.setItem('sessionId', sessionId);
const taskId = start.taskId;

// ② 轮询 tree
const timer = setInterval(async () => {
  const tree = await fetch(API + start.pollTreeUrl).then(r => r.json());
  renderTree(tree);
  if (tree.status === 'completed' || tree.status === 'failed') clearInterval(timer);
}, 2500);
```
