# 协作者本地环境搭建指南

> 克隆本仓库后，按本文把 Hermes Agent 跑起来。  
> 适用：**Windows 10+**（团队当前主环境）；路径示例以 `D:\hermes-xa` 为准，请改成你自己的目录。

---

## 1. 仓库里有什么、没有什么

| 在 Git 里 | 不在 Git 里（需本地安装） |
|-----------|---------------------------|
| `config.yaml` — 模型、MCP、Skill 开关 | `hermes-agent/` — Hermes 核心程序（`install.ps1` 安装） |
| `skills/` — 业务 Skill | `.env` — 密钥、Cookie、代理（**勿提交**） |
| `mcp/` — MCP 源码 + `mcp_servers.yaml` | `sessions/`、`logs/` — 运行时自动生成 |
| `docs/` — 设计与流程文档 | Twitter Cookie 文件、各平台 API Key |

**原则**：业务约束在 **Skill**；MCP 只负责拉数据。改 Skill 不用重装 Hermes；改 MCP 配置要 `/reload-mcp`。

---

## 2. 环境要求

| 组件 | 版本建议 | 用途 |
|------|----------|------|
| Windows | 10+ | 主开发环境 |
| Python | 3.10+（推荐 3.11） | Hermes、Maigret、OCR、Twitter MCP |
| Node.js | 18+ | YouTube / Reddit / Playwright 等 MCP |
| Git | 任意较新版本 | 拉取代码 |
| Tesseract OCR | 5.x + `chi_sim` 语言包 | `mcp_ocr_perform_ocr` |
| 可选 MySQL | 8.x | 后续入库；**仅对话采集可不装** |

内网服务（按团队实际，可在 `config.yaml` / `.env` 修改）：

- 对话模型：`http://172.200.200.4:7000/v1`
- 多模态 vision：`http://172.200.200.1:2015/v1`（须在 `NO_PROXY` 中，否则走代理会超时）

## 3. 一次性安装（新机器）

### 3.1 克隆并设定项目根目录

```powershell
git clone https://github.com/shanzhuZ/hermes-xa.git
cd hermes-xa

# 建议：把仓库根目录设为 HERMES_HOME（与团队一致）
# 用户环境变量 → 新建 HERMES_HOME = D:\hermes-xa（你的实际路径）
# 或在当前 PowerShell 会话：
$env:HERMES_HOME = "D:\hermes-xa"
```

> Hermes 会读 **`%HERMES_HOME%\config.yaml`**。不设 `HERMES_HOME` 时可能落到 `%LOCALAPPDATA%\hermes`，导致读不到本仓库配置。

### 3.2 安装 Hermes Agent

仓库根目录的 `install.ps1` 是 **Hermes 官方安装器**（会拉取 `hermes-agent` 到 `HERMES_HOME\hermes-agent`）：

```powershell
cd D:\hermes-xa
.\install.ps1 -NonInteractive -SkipSetup
```

安装完成后确认命令可用：

```powershell
hermes --version
```

首次可跑向导（换模型等）：

```powershell
hermes setup
```

### 3.3 配置环境变量 `.env`

```powershell
copy .env.example .env
notepad .env
```

**至少按需填写**（向项目负责人索取内网地址与测试 Key）：

```env
# 代理（外网 MCP 常用）
HTTP_PROXY=http://127.0.0.1:7897
HTTPS_PROXY=http://127.0.0.1:7897
# 内网 LLM/VL 必须加入 NO_PROXY
NO_PROXY=172.200.200.1,172.200.200.4,localhost,127.0.0.1

# 平台 MCP
WEIBO_COOKIE=...
YOUTUBE_API_KEY=...
APIFY_TOKEN=...          # Apify（Instagram/Telegram/TikTok/Facebook/GitHub 采集必填）
FIRECRAWL_API_KEY=...    # 若启用 firecrawl MCP
```

**不要**把填好密钥的 `.env` 提交到 Git。

### 3.4 修改本机路径（重要）

仓库里的 `config.yaml` 和 `mcp/mcp_servers.yaml` 含有**作者机器上的绝对路径**，克隆后必须改成你的路径，否则 MCP 起不来。

需要替换的典型项：

| 配置项 | 示例（作者） | 你要改成 |
|--------|--------------|----------|
| 项目根 | `D:/hermes-xa` | 你的克隆路径，如 `E:/work/hermes-xa` |
| Python | `D:/environment/python/python.exe` | 本机 `python` 或 venv 路径 |
| Node | `C:/nvm4w/nodejs/node.exe` | 本机 `node.exe` |
| Tesseract | `C:/Program Files/Tesseract-OCR/tesseract.exe` | 本机安装路径 |
| Twitter Cookie | `C:/Users/zhr/.config/twitter-mcp/cookies.json` | 你的 cookie 文件路径 |

**推荐做法**：

1. 先改 `mcp/mcp_servers.yaml` 里所有 `D:/hermes-xa`、`D:/environment/...`、`C:/Users/zhr/...`
2. 再执行合并脚本（见 3.6），覆盖 `config.yaml` 的 `mcp_servers` 段

路径统一用 **正斜杠** `D:/hermes-xa/...`，避免 YAML 转义问题。

### 3.5 安装 Python / Node 依赖

```powershell
# 进入你配置的 Python（示例）
$py = "D:\environment\python\python.exe"   # 改成你的

# Hermes / MCP 常用包
& $py -m pip install -U pip
& $py -m pip install mcp maigret curl_cffi mcp-ocr pytesseract twitter_mcp

# 各自研 server（按需）
& $py -m pip install -r mcp\servers\maigret-mcp-server\requirements.txt
& $py -m pip install -r mcp\servers\bilibili-mcp-server\requirements.txt

# 微博、微信搜一搜（若 config 里启用）
& $py -m pip install mcp-server-weibo weixin_search_mcp
```

**Tesseract（OCR）**

```powershell
winget install UB-Mannheim.TesseractOCR
```

确认 `mcp/servers/ocr-mcp-server/tessdata/chi_sim.traineddata` 存在；`config.yaml` 里 `TESSDATA_PREFIX` 指向该目录。

**YouTube MCP（必须 build 才有 dist）**

```powershell
cd mcp\servers\youtube-mcp-server
npm install
npm run build
cd ..\..\..
```

生成 `mcp/servers/youtube-mcp-server/dist/stdio-main.js` 后，YouTube MCP 才能被 Hermes 拉起。

**Node 全局 MCP（若 `mcp_servers.yaml` 里用 `.cmd` 启动）**

按 `mcp/README.md` 安装，例如：

```powershell
npm install -g mcp-trends-hub @anthropic/mcp-reddit firecrawl-mcp @playwright/mcp @apify/actors-mcp-server
```

实际命令以你本机 `mcp_servers.yaml` 里的 `command` 为准。

### 3.6 合并 MCP 配置到 config.yaml

```powershell
cd D:\hermes-xa\mcp
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

脚本会把 `mcp_servers.yaml` 合并进项目根目录 `config.yaml`。

### 3.7 Twitter Cookie（采集 Twitter 必填）

1. 按 [twitter_mcp](https://github.com/tradercjz/twitter_mcp) 或团队文档登录并导出 cookie JSON  
2. 放到本机路径，例如 `C:\Users\<你>\.config\twitter-mcp\cookies.json`  
3. 在 `mcp/mcp_servers.yaml` → `twitter.env.TWITTER_COOKIES` 写该路径  
4. 重新执行 `mcp/install.ps1`

## 4. 验证安装

### 4.1 检查 MCP 连通性

```powershell
hermes mcp list
hermes mcp test twitter
hermes mcp test maigret
hermes mcp test youtube
hermes mcp test ocr
hermes mcp test apify
```

`test` 显示 `Connected` 即基本正常。YouTube 失败时先检查是否 `npm run build`。

**Apify 注意**：

- `.env` 中 `APIFY_TOKEN` 从 [Apify Console → Integrations](https://console.apify.com/account/integrations) 获取
- `NO_PROXY` 须包含 `api.apify.com,apify.com,.apify.com`（Apify REST API 直连，避免代理 TLS 超时；Actor 爬取在云端）
- `mcp_servers.yaml` 已预置 5 个 Actor，与旧 Hermes 一致：`facebook`、`tiktok`、`instagram`、`telegram`、`github`
- 01 采集 Skill 中无 MCP 平台走 Apify 三轮：`Actor → get_actor_run → get_dataset_items`（见 `skills/.../references/apify-actors.yaml`）

### 4.2 启动对话

```powershell
cd D:\hermes-xa
hermes chat
```

会话内：

```text
/reload-mcp
/tools
```

MCP 较多时 `/tools` 只显示核心工具 + `tool_search`，属正常现象。

### 4.3 试跑 01 采集 Skill


或：


## 5. 日常协作：拉代码后要做什么

```powershell
git pull
```

| 变更类型 | 你要做的 |
|----------|----------|
| 只改了 `skills/**` | 新开会话或 `/skill account-intelligence-collect` 即可 |
| 改了 `mcp/mcp_servers.yaml` | 改路径 → `mcp/install.ps1` → 会话里 `/reload-mcp` |
| 改了 `mcp/servers/**` Python | `pip install -r ...`（如有新依赖）→ `/reload-mcp` |
| 改了 YouTube MCP 源码 | `npm run build` → `/reload-mcp` |
| 改了 `config.yaml` 模型/vision | 重启 `hermes chat` |
| 改了 `.env.example` | 对照更新本地 `.env`（不覆盖已有密钥） |

**建议**：改 MCP 配置只改 `mcp/mcp_servers.yaml`，合并后再提交，避免多人直接改 `config.yaml` 冲突。

## 7. 常见问题

### MCP 工具搜得到但调用失败

- YouTube：未 `npm run build`，缺少 `dist/stdio-main.js`
- 路径错误：`config.yaml` 里 `command` / `args` 仍指向他人机器路径
- 改配置后未 `/reload-mcp`

### Maigret 报 `UnicodeDecodeError: gbk`

Windows 控制台编码问题，多数情况下 **扫描仍可能成功**。确保子进程 env 含 `PYTHONUTF8=1`（已在 `mcp_servers` 配置）。若持续失败，用新会话重试。

### `vision_analyze` 失败 / 超时

- 检查 `config.yaml` → `auxiliary.vision.base_url` 是否可达  
- `.env` 的 `NO_PROXY` 须包含内网 VL 地址（如 `172.200.200.1`）

### Agent 输出画像报告、不按三节模板

- 确认加载的是 `account-intelligence-collect`，**不要**加载 `account-intelligence-profile`（已归档）  
- 新开会话，让 Agent 读取 `references/output-template.md`

### `hermes` 命令找不到

- 重新打开终端，或把 Hermes 安装目录加入 PATH  
- 确认 `install.ps1` 已成功执行

- **不要提交** `.env`、`auth.json`、Cookie、真实 API Key

- Skill / 文档改动直接提交；大改 `config.yaml` 前与负责人对齐（模型地址、内网 IP）
