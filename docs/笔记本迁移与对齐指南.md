## 1. 从台式机拷贝的文件（U 盘 / 网盘 / 局域网共享）

> **必须由用户手工拷贝**（Git 不包含这些）。拷贝前 **两台机器都关闭 Cursor 和 hermes gateway**。

### 1.1 必拷（缺了跑不起来）

| 台式机路径 | 笔记本目标路径 | 说明 |
|-----------|---------------|------|
| `D:\hermes-xa\.env` | `D:\hermes-xa\.env` | 数据库、API Key、代理、gateway 端口 |
| `D:\hermes-xa\config.yaml` | `D:\hermes-xa\config.yaml` | 模型、MCP、db_sink hooks（含台式机路径，后面要改） |

### 1.2 强烈建议拷（与台式机行为一致）

| 台式机路径 | 笔记本目标路径 | 说明 |
|-----------|---------------|------|
| `D:\hermes-xa\auth.json`（若存在） | 同路径 | OAuth 认证 |
| `C:\Users\zhr\.config\twitter-mcp\cookies.json` | 笔记本对应用户目录 | Twitter MCP 必填；路径见下文 |
| `D:\hermes-xa\mcp\servers\ocr-mcp-server\tessdata\` | 同路径 | OCR 中文语言包 |

### 1.3 二选一：Hermes 核心程序

`hermes-agent/` **不在 Git 里**，任选一种：

**方案 A（推荐）— 笔记本重新安装**

```powershell
cd D:\hermes-xa
$env:HERMES_HOME = "D:\hermes-xa"
.\install.ps1 -NonInteractive -SkipSetup
```

**方案 B — 直接拷整个目录**

| 台式机 | 笔记本 |
|--------|--------|
| `D:\hermes-xa\hermes-agent\` | `D:\hermes-xa\hermes-agent\` |

> 方案 B 更快，但笔记本 Python 版本不一致时可能需重装 venv。

### 1.4 数据库（按需）

| 场景 | 做法 |
|------|------|
| 笔记本连台式机 MySQL（同局域网） | `.env` 里 `HERMES_DB_HOST` 改为台式机 IP，库名 `hermes-xa` |
| 笔记本本地独立 MySQL | 在台式机导出 `mysqldump hermes-xa`，笔记本导入；`.env` 保持 `127.0.0.1` |
| 仅测对话、不入库 | `.env` 设 `HERMES_PERSIST_ENABLED=0`（功能受限） |

### 1.5 不要拷（会导致异常）

| 不要拷 | 原因 |
|--------|------|
| `logs/`、`cache/`、`sessions/` | 运行时垃圾 |
| `hermes-agent\venv\` | 跨机器常不可用 |
| `%APPDATA%\Cursor\User\globalStorage\state.vscdb` | 会导致 Cursor Loading Chat 卡死、历史空白 |
| `node_modules/`、`__pycache__/`、`target/` | 到笔记本重装更快 |

## 3. 修改本机路径（关键步骤）

台式机 `config.yaml` 和 `mcp/mcp_servers.yaml` 含**绝对路径**，必须在笔记本上替换。

### 3.1 探测笔记本路径

```powershell
where.exe python
where.exe node
where.exe tesseract
python --version
node --version
```

记录结果，例如：

- Python：`C:\Users\xxx\AppData\Local\Programs\Python\Python311\python.exe`
- Node：`C:\Program Files\nodejs\node.exe`

### 3.2 需要替换的典型路径

在 `config.yaml` 和 `mcp/mcp_servers.yaml` 中全局替换：

| 台式机（旧） | 笔记本（新） |
|-------------|-------------|
| `D:/environment/python/python.exe` | 本机 `where python` 结果（用正斜杠） |
| `D:/hermes-xa` | `D:/hermes-xa`（若路径相同可不动） |
| `C:/nvm4w/nodejs/node.exe` | 本机 `where node` 结果 |
| `C:/Program Files/Tesseract-OCR/tesseract.exe` | 本机 Tesseract 路径 |
| `C:/Users/zhr/.config/twitter-mcp/cookies.json` | `C:/Users/<笔记本用户名>/.config/twitter-mcp/cookies.json` |

**特别注意 `config.yaml` → `hooks` 段**（db_sink 入库 Hook）：

```yaml
hooks:
  pre_llm_call:
  - command: <本机python>/D:/hermes-xa/scripts/db_sink.py
  post_tool_call:
  - command: <本机python>/D:/hermes-xa/scripts/db_sink.py
  ...
```

四处 hook 的 `command` 必须指向笔记本真实 Python + `D:/hermes-xa/scripts/db_sink.py`。

### 3.3 合并 MCP 配置

路径改完后执行：

```powershell
cd D:\hermes-xa\mcp
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

## 4. 安装依赖

### 4.1 Python 入库 Hook 依赖

```powershell
cd D:\hermes-xa
python -m pip install -U pip
python -m pip install -r scripts\requirements-persist.txt
```

### 4.2 MCP 相关 Python 包

```powershell
python -m pip install mcp maigret curl_cffi mcp-ocr pytesseract twitter_mcp mcp-server-weibo weixin_search_mcp
python -m pip install -r mcp\servers\maigret-mcp-server\requirements.txt
python -m pip install -r mcp\servers\bilibili-mcp-server\requirements.txt
```

### 4.3 Tesseract OCR

```powershell
winget install UB-Mannheim.TesseractOCR
```

确认 `mcp/servers/ocr-mcp-server/tessdata/chi_sim.traineddata` 存在。

### 4.4 YouTube MCP（必须 build）

```powershell
cd D:\hermes-xa\mcp\servers\youtube-mcp-server
npm install
npm run build
cd D:\hermes-xa
```

确认存在：`mcp/servers/youtube-mcp-server/dist/stdio-main.js`

### 4.5 Node 全局 MCP（按 mcp_servers.yaml 里的 command 安装）

```powershell
npm install -g @apify/actors-mcp-server @playwright/mcp firecrawl-mcp reddit-mcp-buddy mcp-trends-hub
```

以 `mcp/mcp_servers.yaml` 实际引用的包为准。

### 4.6 Java 后端（若要跑前端对接 API）

```powershell
cd D:\hermes-xa\clients\hermes-xa
mvn clean package -DskipTests
# 启动：java -jar target/*.jar  或在 IDE 运行 AwApplication
# 默认端口 4377（见 application.yml）
```

## 9. 常见问题处理

### `hermes` 读不到本仓库 config

→ 设置 `HERMES_HOME=D:\hermes-xa`，重启终端。

### MCP 全部失败

→ 检查 `config.yaml` 里 Python/Node 路径；执行 `mcp/install.ps1`；`hermes mcp test <name>` 逐个排查。

### db_sink 不入库

→ 检查 `config.yaml` hooks 四处 `command` 路径；检查 `.env` 的 `HERMES_PERSIST_ENABLED=1` 和 MySQL 连通性；看 `logs/*_sink.log`。

### skills 只有两类

→ 多半在 **main** 分支；执行 `git checkout fox && git reset --hard origin/fox`。

### Cursor Loading Chat 卡住

→ 不要用台式机的 `globalStorage\state.vscdb`；删掉笔记本上错误的拷贝，重启 Cursor，开新对话。
